# Demostración · Página de gestión para Yedeco

Demostración de una página de gestión para **Yedeco**, barraca y venta de materiales de
construcción, desarrollada por **Wydan Solutions**: mostrador con lector de código de barras,
stock con lotes y vencimientos, presupuestos, acopios de obra, entregas con hoja de ruta,
compras y proveedores, cuentas corrientes, la comisión del vendedor por escala mensual y finanzas.

- Los **artículos** son los de la lista de Yedeco. **Cantidades, precios, clientes, proveedores,
  ventas y movimientos son inventados** para la demostración.
- Funciona por completo en el navegador: no hay servidor ni base de datos.
- Contraseña de la demostración: `1234` (sirve para los tres usuarios: Carolina, Alan y Lucas).

Cada persona que abre la página trabaja con su propia copia de los datos de ejemplo,
guardada solo en su navegador.
